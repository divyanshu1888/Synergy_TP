## 5. What Was Learned
This task clarified the conceptual vocabulary needed before analyzing domain data: the difference between an observation and a variable, the distinction between categorical and numerical data, and how raw data differs from processed data. It also reinforced why measurement units and experiment context must always accompany a numerical value - two numbers with the same magnitude (e.g., pH 7 and 7 volts) can represent entirely unrelated physical quantities, so unit and context checks must happen before any comparison or calculation. Finally, it covered basic summary statistics (mean, median, min, max, range) and why the mean can be misleading in the presence of outliers or mixed conditions, along with a checklist of questions to ask before analyzing a dataset received from another team.
